AIS HOMEPAGE — DOCUMENTARY IMAGE UPDATE
=========================================

This package updates the AIS homepage to use enhanced high-resolution stills
taken from the documentary frames supplied for this revision.

Included:
- index.html
- main.js
- homepage-image-overrides.css
- 8 enhanced 3840px-wide JPG images

Homepage changes:
1. Hero background -> AIS campus documentary frame.
2. AIS Journey -> real Early Years classroom frame.
3. AIS Journey stages -> real classroom/teacher imagery for Primary/JHS.
4. School Life feature -> real AIS classroom/teacher frame.
5. Facilities -> real AIS classroom frame; Sports and Campus tabs now use supplied documentary frames.
6. Gallery -> real campus, Early Years, campus-life/walkway and sports imagery.

The original documentary screenshots included VLC/player chrome. Those borders,
controls and taskbar areas were cropped out before enhancement.

The images were upscaled to 3840px wide and given restrained tonal/color/sharpness
enhancement while preserving the original photographic content.

Repository target:
fadl462/ais-website-1

Files are arranged using the same paths expected by the repository.
